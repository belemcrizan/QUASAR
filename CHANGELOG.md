# Changelog

## 0.2.0 - Research hardening

- Added temperature, Platt, and isotonic calibration behind one interface.
- Added a dependency-free Isolation Forest baseline.
- Added multi-seed aggregation with mean, standard deviation, and 95% confidence intervals.
- Added automated evidence ablations and Markdown reports.
- Added opt-in scalability benchmarks up to one million observations.
- Added IEEE-CIS and NASA/MAST light-curve CSV ingestion paths without automatic downloads.
- Added configurable detector thresholds, forecast horizons, and logistic/ensemble forecasting.
- Converted the public documentation to English and documented the research and product-wedge boundaries.

## 0.1.0 - Initial POC

- Domain-neutral contracts, rolling background, information dynamics, evidence fusion, forecasting, temporal validation, synthetic fraud and astronomy adapters, CLI, optional API, tests, and local artifacts.
