# Experiment A - Fraud/surveillance

Status: registered synthetic POC. Run `python experiments/experiment_a_fraud/run.py` after installation.

The experiment uses only synthetic records. It tests whether the shared core can combine moderate changes in transaction amount, velocity, counterparty risk, and network density. It does not claim to detect real fraud.

Generated `results.json` and `artifacts/` are intentionally ignored by Git. Report positive and negative outcomes; do not hand-pick seeds.
