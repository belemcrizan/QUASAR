# Security policy

## Supported status

QUASAR v0.2.0 is a research POC, not a production security boundary. No release is currently approved for public internet exposure or regulated automated decisions.

## Reporting

Report suspected vulnerabilities privately to the repository owner. Do not include credentials, restricted datasets, personal data, or exploit details in a public issue.

## Current exclusions

The optional API has no authentication, authorization, rate limiting, tenant isolation, or production hardening. Local artifact files may contain source identifiers and evaluation labels. Use synthetic or properly governed data until a formal threat model and data-handling policy are implemented.
