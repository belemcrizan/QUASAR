# English overview

The repository root README is the canonical international overview for QUASAR v0.2.0.

QUASAR is a local, domain-agnostic research POC for weak-signal discovery, information dynamics, probabilistic forecasting, and chronological falsification. It includes repeated-seed statistics, calibration studies, Isolation Forest, ablations, scalability studies, real-data ingestion paths, and international Markdown reports.

See ../README.md for setup and commands. No production, causal, novelty, or superiority claim is made.
